# Header / Footer Background Assets

These are intentionally free of decorative lines, dots, icons, logos and text.

## Header
- header-dark-primary-desktop.webp
- header-dark-primary-mobile.webp

Use behind the navigation/header.
Designed to blend directly into `bg-01-dark-primary-*` hero backgrounds:
- darker/calm at the top for nav readability
- texture remains at the edges
- lower edge opens into the hero rather than creating a hard band

## Footer
- footer-dark-primary-desktop.webp
- footer-dark-primary-mobile.webp

Use as the footer background.
Designed as the closing state of the same Dark Primary visual family:
- upper edge can blend into a dark section / transition
- texture settles toward lower edges
- central area remains calm for sigil + footer text
- no decorative linework

Recommended:
- background-size: cover
- background-position: center
- do not add extra line/node overlays to header/footer
